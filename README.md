# URL Shortener

A full-stack URL shortener application built with Spring Boot backend and a frontend to be added.

## Project Structure

- **Backend**: Spring Boot application for URL shortening APIs
- **Frontend**: To be added (planned as separate component)

## Tech Stack

### Backend
- Java 25
- Spring Boot 4.1.0
- Spring Web MVC
- Maven
- Lombok

## Getting Started

### Prerequisites
- Java 25+
- Maven 3.8+

## Features (Planned)

- [ ] Create short URLs
- [ ] Redirect short URLs to original links
- [ ] Track URL statistics
- [ ] Frontend UI
